# specs/

Per-issue `spec.md` / `plan.md` / `tasks.md` artifacts for **unsettled** sub-issues, written using
the Spec Kit `/speckit-specify` → `/speckit-plan` → `/speckit-tasks` commands before
implementation begins.

See `.specify/memory/constitution.md` Principle VII and `.github/copilot-instructions.md`
("Before writing code" and "Unsettled issues only") for the rule that decides which issues get a
folder here, and the exact steps.

Convention: `specs/<issue-number>-<slug>/{spec.md,plan.md,tasks.md}`

Files here are a permanent record and are never deleted, even after the issue they document is
closed. This folder only started being populated from issue #6 onward — earlier issues (#4, #5)
were not retroactively backfilled.
